# Milk · D&D 改造项目

这是基于 Milk 原始项目建立的独立改造副本。当前版本处于**阶段 1：基础整理与兼容性准备**。

## 当前状态

- 保留原项目的 HTML、CSS、JavaScript 文件结构与脚本加载顺序。
- 暂不改变聊天、字卡抽取、随机回复、延迟、已读不回、引用回复等既有机制。
- 暂不改变原有数据键、会话 ID、IndexedDB/localForage 配置及备份格式。
- 本阶段新增项目说明文档，不对原始业务代码做重写。

## 本地运行

这是一个静态网页项目，没有 npm 安装或构建步骤。可以使用本地静态文件服务器打开，也可以部署到 GitHub Pages。

直接双击 `index.html` 在部分浏览器环境下可能受到本地文件访问限制；如遇到加载或存储异常，请通过静态服务器访问。

## GitHub Pages 部署

1. 在 GitHub 创建一个新的空仓库。
2. 解压本项目 ZIP。
3. 将解压后文件夹中的全部内容上传到仓库根目录（应能直接看到 `index.html`、`css/` 和 `js/`）。
4. 在仓库的 **Settings → Pages** 中，将部署来源设为 **Deploy from a branch**。
5. 选择 `main` 分支和 `/(root)`，保存并等待部署完成。

如果仓库名不是 `用户名.github.io`，GitHub Pages 通常会通过仓库子路径提供网站。本项目现有资源路径需要在后续兼容性检查中继续核验；若部署后样式或脚本未加载，请先不要删除或移动文件，把页面报错或截图发回检查。

## 项目结构

- `index.html`：页面结构与脚本入口
- `css/styles.css`：页面样式
- `js/`：应用逻辑与各功能模块
- `PROJECT_STATUS.md`：改造阶段、保护规则与已知风险

## 数据安全提醒

网站数据主要保存在当前浏览器的本地存储中。清理浏览器数据、切换浏览器或设备可能影响数据可用性。进行任何升级或改造测试前，请先使用应用原有备份功能导出备份，并妥善保存备份文件。
