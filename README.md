# Milk · D&D 改造项目

这是基于 Milk 原项目建立的独立改造副本，目标是保留原有功能与字卡传讯机制，并逐步将视觉和界面表达调整为 D&D / 奇幻传讯语境。

## 当前进度

项目目前处于**阶段 2（整体视觉改造）与阶段 3（世界观命名统一）的早期阶段**。已完成启动流程调整、基础森林绿/羊皮纸主题、聊天主界面第一批视觉调整，以及部分主界面入口的可见名称改造。

详细的已完成事项、待办事项、保护规则和后续阶段请查看 [`PROJECT_STATUS.md`](./PROJECT_STATUS.md)。

## 本地运行

这是一个静态网页项目，没有 npm 安装或构建步骤。可以使用本地静态文件服务器打开，也可以部署到 GitHub Pages。

直接双击 `index.html` 在部分浏览器环境下可能受到本地文件访问限制；如遇到加载或存储异常，请通过静态服务器访问。

## GitHub Pages 部署

1. 在 GitHub 创建一个新的空仓库。
2. 解压项目 ZIP。
3. 将解压后文件夹中的全部内容上传到仓库根目录（应能直接看到 `index.html`、`css/` 和 `js/`）。
4. 在仓库的 **Settings → Pages** 中，将部署来源设为 **Deploy from a branch**。
5. 选择 `main` 分支和 `/(root)`，保存并等待部署完成。

如果仓库名不是 `用户名.github.io`，GitHub Pages 通常会通过仓库子路径提供网站。项目资源路径和外部依赖仍需在后续兼容性检查中继续核验。

## 数据安全提醒

网站数据主要保存在当前浏览器的本地存储中。清理浏览器数据、切换浏览器或设备可能影响数据可用性。进行升级或恢复测试前，请先使用应用原有备份功能导出备份，并妥善保存备份文件。当前“重置数据”操作存在清理范围过大的风险，修复前不要用真实数据测试。
